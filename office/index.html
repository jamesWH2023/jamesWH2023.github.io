    How it works

    Add agents

    Open Agents, fill name, role, and instructions, pick a desk accent, then save. Agents persist in localStorage under agent-office:v1.

    Assign tasks

    Open Assign task, write a brief, select one or more agents, and start. The prototype runner advances status through queued → researching → drafting → reviewing → done, with progress shown on desks and the task board.

    Wire real agents next

    Replace the simulated runner in js/runner.js. The AgentRunner interface accepts a task + agent profiles and emits progress events. Point it at Cursor Agent SDK / your backend — see office/README.md.
