    How it works

    3D loft

    The room, desks, agents, lamps, and wall board are WebGL meshes (Three.js). HTML overlays handle forms and task status.

    Add agents

    Open Agents, set name, role, and instructions, pick an accent, save. Data lives in localStorage under agent-office:v1. Tap a desk in the scene to inspect.

    Assign tasks

    Open Assign task, write a brief, select agents, start. Lamps glow and agents animate while the simulated runner advances stages on the HUD board.

    Wire real agents

    Swap createRunner() in js/runner.js for your Cursor / Agent SDK client — see office/README.md.
